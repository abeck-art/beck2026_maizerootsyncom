# beck2026_maizerootsyncom
Supplementary data, models, and Python code for Beck et al. 2026

Supplemental materials supporting the research article: "Genome-scale community metabolic modeling of maize root-associated microbiota predicts root exudates to stimulate more diverse metabolic interactions", Ashley E. Beck, Anna-Katharina Garrell, Henry Phillip, Charles Said, Manuel Kleiner.

Supplemental File S2: Biolog data for seven SynCom species

Supplemental File S3: Code for (1) constructing individual metabolic models with CarveMe, (2) performing FBA simulations to compare individual species models with and without Biolog data, (3) setting substrate uptake constraints for each species model incorporating Biolog data in both minimal and exudate medium, (4) performing FBA simulations comparing minimal and exudate media on an equal substrate uptake basis, (5) creating community models, (6) performing community FBA model simulations, (7) sensitivity testing for individual bacterial models in exudate medium, and (8) assigning growth/nongrowth states to Biolog data for each bacterial species

Supplemental File S4: Zipped folder containing SBML models, media library, and soft constraint files

Supplemental File S5: Primary substrate sensitivity analysis for seven SynCom species
